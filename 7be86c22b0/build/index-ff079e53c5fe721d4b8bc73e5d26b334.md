<div class="uwtn-entry"><div class="uwtn-entry-text"><h2><a href="/faults-on-an-add-on-mesh/">Faults and patch-refinement of the mesh</a></h2><div class="uwtn-entry-summary">A slipping fault is a discontinuity the mesh has to represent, along a trace that moves as the model runs. We build the fault into a short-lived mesh made from a static base. The base holds the state, the partition and the coarse multigrid levels; the add-on is a copy of the base's finest level with the fault placed into it as a narrow structured band, split along the fault, and rebuilt from the base whenever the fault moves.</div></div></div>
