# Underworld Technical Notes — previews

**This repository holds build output. It has no sources, and nothing here is
published.**

Each directory is a preview of one branch of
[underworldcode.org](https://github.com/Underworld-Technical-Notes/underworldcode.org),
built by that repository's `preview` workflow and named for a hash of the
branch. The hash is stable, so a link keeps working as the branch is updated,
and meaningless, so the drafts in flight cannot be read off this site.

Every page is served `noindex, nofollow`, carries a banner saying which branch
and commit it came from, and `robots.txt` here disallows everything. A draft
that a search engine indexed would compete with the real article for its own
title — and those articles are the targets of fifty registered DOIs.

**The published site is [www.underworldcode.org](https://www.underworldcode.org).**

Directories are safe to delete once a branch is merged; the next preview
recreates whatever is still live.
