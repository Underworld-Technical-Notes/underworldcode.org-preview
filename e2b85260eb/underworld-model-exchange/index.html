Model exchange

The underworld-community organisation on GitHub collects models built with Underworld and shared by the people who built them. It is a place to put a model so that others can run it, not a curated library: repositories arrive when their authors publish, they vary in how much explanation they carry, and some accompany a paper while others are working material.

That is worth saying plainly rather than presenting a tidy catalogue that the collection does not have. If you are looking for a worked example to start from, the technical notes here are the better entry point — they are written to be read. If you are looking for the model behind a particular result, the repository named for its authors is usually the one you want.

Adding a model¶

Anyone using Underworld can contribute. A useful repository has the model script, enough of a README to say what the model is and what it produced, and a note of the Underworld version it was run against — that last one matters more than it looks, because the API has moved.

Ask on GitHub Discussions if you would like a repository added to the organisation.
